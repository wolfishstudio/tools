📥 Baixar Wolfish.Maia (.nupkg)

Instalação via .NET CLI

Se você já possui o .NET 10 SDK instalado, pode instalar globalmente via terminal:

dotnet tool install --global wolfish.maia

Para atualizar a ferramenta para a versão mais recente:

dotnet tool update --global wolfish.maia

Instalação via PowerShell

Se você não possui o .NET 10 SDK instalado, pode instalar globalmente via PowerShell:

irm https://wolfishstudio.github.io/tools/install.ps1 | iex
